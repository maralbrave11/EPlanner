# 006 — Free, no daily question limit

**Decision (2026-10-31):** The app is free for users and has no daily question limit. No payments.

- No payment provider is needed (keeps the Next.js / Supabase / Vercel-only stack).
- Risk: AI (Claude) cost grows with usage and is paid by the owner. Can be revisited later (e.g., add a limit or a paid plan) if costs get too high.
