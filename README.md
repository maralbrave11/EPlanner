# SmartTrip (EPlanner)

Travel-planning website that builds a personalized, continuously improving trip plan.
Stack: Next.js + Supabase. See `docs/plan.md` and `CLAUDE.md`.

## Setup

1. `npm install`
2. Copy `.env.example` to `.env.local` and fill in your Supabase URL and anon key.
3. `npm run dev` → http://localhost:3000
